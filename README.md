# Supreme Aircon — Official Website Revamp

Modern, mobile-first public website for **Supreme Aircon**, an authorized Daikin HVAC Sales, Installation, and Service partner with over 20 years of experience based in Vashi, Navi Mumbai.

## Features

- **Responsive & Clean UI**: Built with HTML5, Tailwind CSS, and Plus Jakarta Sans typography.
- **Auto-Changing Hero Showcase**: Seamless crossfade slider highlighting residential installations, commercial VRV solutions, and emergency maintenance.
- **Service Catalog**: Detailed service cards for Power Jet Foam Servicing, Gas Refill & Leak Testing, Certified Installation, and Inverter PCB Repair with interactive hover lift animations.
- **Commercial & Home VRV**: Dedicated section for turnkey centralized HVAC, concealed ductable ACs, and architect collaboration.
- **Annual Maintenance Plans (AMC)**: Transparent breakdown of Standard and Comprehensive AMC plans with interactive elevation animations.
- **Navi Mumbai Coverage**: Hyper-local service nodes (Vashi, Sanpada, Nerul, Seawoods, Belapur, Kharghar, Airoli, Panvel, etc.).
- **Quick Booking & WhatsApp Dispatch**: Modal service scheduler with instant callback dispatch and direct WhatsApp integration.

## Running Locally

You can open `index.html` directly in any modern browser, or run a local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node / npx
npx serve .
```

Then visit [http://localhost:8000](http://localhost:8000).
